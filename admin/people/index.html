Sign in with GitHub

Only people with write access to traffic-arclab/traffic-arclab.github.io can save. Use a GitHub personal access token:

  1. Open GitHub → Settings → Tokens (classic) → Generate new token (the link pre-selects the only permission needed, public_repo).
  2. Pick an expiration date, then Generate token.
  3. Copy the token (it starts with ghp_) and paste it here.

Use a classic token: fine-grained tokens cannot write to a repository owned by another user account, which is the case for traffic-arclab. Your GitHub account must be a collaborator of the repository with write access.
