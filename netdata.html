Network data management

We are working on methodologies and techniques to manage huge amounts of monitoring data (OSNs, p2p, high speed links, ...) from both active and passive approaches.

Network data compression

We are developing a compressed representation technique for network monitoring data that provides:

  • reduced memory footprint for stored data, trading off accuracy versus space occupation;
  • a wide class of operations allowed directly on compressed data with no need for decompression and with reduced time complexity.
The research has been partially conducted during a summer internship by Mr. Giuseppe Aceto at DOCOMO Innovations Inc. (formerly Docomo Communications Laboratories USA), Palo Alto, CA.

Papers & Technical Reports

Giuseppe Aceto, Alessio Botta, Antonio Pescapè, Cedric Westphal, "An efficient storage technique for network monitoring data", IEEE International Workshop on Measurements & Networking (M&N 2011), Capri, Italy, October 2011.

Network data reduction

We are working on an entropy-based methodology to reduce network traffic data which provides several advantages:

  • there is no need to consider the entire data sets in the processing stage;
  • allows to work off-line on reduced data.

Papers & Technical Reports

A. Pescapè, "Entropy-Based Reduction of Traffic Data", IEEE Communications Letters, pp. 191-193, Vol.11, No.2 - February 2007.

Alessio Botta, Alberto Dainotti, Antonio Pescapè, Giorgio Ventre, "Reducing Network Traffic Data Sets", 2007 IEEE International Conference on Communications (ICC 2007)
