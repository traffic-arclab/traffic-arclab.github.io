2. Analysis and Performance Evaluation
over Windows platform

Windows Platform: local experimentation

Local experimentation with logging only at receiver side

Over Windows platform and by using the log file at the receiver side, D-ITG presents the performance depicted in Figure 1.

Figure 1: Comparative analysis of local received
data rate over Windows platform (log at receiver side)

In the case of C=30000pkt/s, c=1024byte, t=60s D-ITG reaches a received data rate equal to 241Mbit/s with a percentage loss rate equal to 1.8%. At the same received data rate Iperf and Mtools present respectively a loss rate equal to 38% and 5.3%. In addition, in section 4.1.1 we have already clarified that the Iperf logging process does not permit a complete performance analysis. In Figure 2 the percentage loss rate (between real and expected data rate) as a function of packet rate is reported. In Figure 3 the percentage loss rate trend is depicted.

Figure 2: Local received data rate over
Windows platform (log at receiver side) 		Figure 3: Local loss rate (%) over
Windows platform (log at receiver side)

Local experimentation with logging both at receiver and sender side

In this subsection we can analyze only D-ITG because there are not traffic generators, over Windows platform, that can log both at sender and receiver side. In this case, D-ITG presents a reduction of 102 Mbps (Figure 4). Indeed in this case, with a percentage loss rate equal to 1.8%, we had a max data rate equal to 143 Mbps for 17500 pkt/s (in the previous case for the same percentage loss rate we had a max data rate equal to 245 Mbps for 30000 pkt/s). In Figure 5 and in Figure 6 the percentage loss rate respectively at sender and receiver side is depicted.

Before to study the performance in a distributed testbed, we can conclude that under the same conditions, over Windows platforms the maximum data rate is less than maximum value over Linux platforms.

Windows Platform: distributed experimentation

In this subsection we describe the results of the distributed experimentation over Windows platform. In this case we used the same operational mode of the section "Windows Platform: local experimentation".

Distributed experimentation with logging only at receiver side

Between two Windows devices and by using the log file at the receiver side D-ITG present the performance depicted in Figure 7. In Figure 8 a percentage loss rate (between real and expected data rate) as a function of packets per second number is reported. In the case of C=30000pkt/s, c=1024byte, t=60s D-ITG reaches a received data rate equal to 242Mbit/s with a percentage loss rate equal to 1.4%.
