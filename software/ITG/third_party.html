Third-party software

If you are using D-ITG for scientific papers, academic lectures, project reports, or technical documents, please help us increasing D-ITG impact by adding a reference to:
A. Botta, A. Dainotti, A. Pescapè, "A tool for the generation of realistic network workload for emerging networking scenarios", Computer Networks (Elsevier), 2012, Volume 56, Issue 15, pp 3531-3547. (Article) (BibTex)

Mobile D-ITG APP for Android by Cem Akpolat

The mobile APP acts as a wrapper for the command line tools included in the D-ITG software. It should support all features of version 2.8.1.

The APP is provided and supported by Cem Akpolat, email: akpolatcem(at)gmail.com.

GUI made by Volker Semken for D-ITG

The GUI is written in Java and acts as a wrapper for the command line tools included in the D-ITG software. It should support all features of version 2.6 and new features of 2.7b, except the source interface in versions up to version 2.8.0.

The GUI is provided and supported by Volker Semken, email: volker(at)semken.com.

JITGApi

A complete, native Java implementation of the C++ libITG API. It builds as a jar and may be imported into any Java program. Full JavaDoc and unit tests are also provided.
The source code is available on github.

The API is provided and supported by Duncan Eastoe, email: duncaneastoe@gmail.com.

ITGController

A Java remote control tool for ITGSend which uses JITGApi. It allows running of a specified configuration file to control and monitor multiple ITGSend daemon instances.
The source code is available on github.

The controller is provided and supported by Duncan Eastoe, email: duncaneastoe@gmail.com.
